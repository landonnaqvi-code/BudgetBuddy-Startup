# Release Notes

Every time your squad ships something, add a short entry at the top. Newest
release goes first. Keep each entry to what a user would notice.

## Format

```
## v1.0 - YYYY-MM-DD
### Added
- A user survey at the start of the app that takes in user data regarding their financial situation. https://github.com/landonnaqvi-code/BudgetBuddy-Startup/pull/3
- A feature where all transactions over a certain spending threshold are shown to the user so they can see what they spend most on. https://github.com/landonnaqvi-code/BudgetBuddy-Startup/pull/8
- A feature where the user can access their survey data at any moment so that they can analyze their current finances and priorities and make the best, most informed decisions. https://github.com/landonnaqvi-code/BudgetBuddy-Startup/pull/9
### Fixed
- What was broken and now works.
### Changed
- The menu option has two extra choices for the user and there is now a survey at the start of the program.
```
